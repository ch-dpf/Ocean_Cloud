所有示例以各文档标明的工作目录执行。页面采用正式业务文案，工程说明只放在文档中。

本目录中的开发教程、规范、架构和后端接入说明随源码提交，作为正常开发与交接资料。测试报告、运行日志、临时截图和个人任务记录不纳入本目录交付。
